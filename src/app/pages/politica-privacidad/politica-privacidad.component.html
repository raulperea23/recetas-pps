1. Responsable del tratamiento

En cumplimiento del Reglamento (UE) 2016/679 del Parlamento Europeo y del Consejo (RGPD) y la Ley Orgánica 3/2018, de 5 de diciembre, de Protección de Datos Personales y garantía de los derechos digitales (LOPDGDD), le informamos de que el responsable del tratamiento de los datos personales recogidos en este sitio web es:

  • Titular: TITULAR_DE_LA_WEB
  • Sitio web: recetas-pps.web.app
  • Correo electrónico: CORREO_DE_LA_WEB

2. Datos que recopilamos

Este sitio web es de carácter informativo y no recopila datos personales de sus visitantes. Concretamente:

  • No se requiere registro ni creación de cuenta para acceder al contenido.
  • No se utilizan formularios de contacto ni de suscripción.
  • No se recopilan datos de navegación con fines analíticos.
  • No se comparten datos con terceros con fines publicitarios.

El único área restringida es el panel de administración, accesible exclusivamente por el titular del sitio mediante autenticación con correo electrónico y contraseña, gestionada a través de Firebase Authentication (Google LLC). En este caso, los datos de acceso son tratados única y exclusivamente para permitir la gestión del contenido del sitio.

3. Política de cookies

Una cookie es un pequeño archivo de texto que un sitio web almacena en el dispositivo del usuario. Este sitio web utiliza únicamente cookies técnicas estrictamente necesarias para su funcionamiento, las cuales no requieren consentimiento del usuario según la normativa vigente.

Cookies propias utilizadas

Nombre Finalidad Tipo Duración
pps-theme Guardar la preferencia de modo claro u oscuro seleccionada por el usuario Técnica / Preferencia Persistente (localStorage)
firebase:authUser Mantener la sesión del administrador del sitio web Técnica / Sesión Persistente (localStorage)
pps-sugerencia-dia Guardar la receta sugerida del día para que no cambie hasta el día siguiente Técnica / Preferencia 1 día (localStorage)

Cookies de terceros

Este sitio web utiliza los servicios de Firebase (Google LLC) para el almacenamiento de datos y la autenticación del administrador. Firebase puede almacenar datos técnicos necesarios para el funcionamiento del servicio. Para más información, consulte la política de privacidad de Google .

Las imágenes del sitio web son servidas a través de Cloudinary (Cloudinary Ltd.), un servicio de gestión de imágenes en la nube. Para más información, consulte la política de privacidad de Cloudinary .

Cómo gestionar las cookies

Dado que este sitio solo utiliza cookies técnicas esenciales, no es posible desactivarlas sin afectar al funcionamiento del sitio. No obstante, puede eliminarlas en cualquier momento desde la configuración de su navegador:

  • Google Chrome
  • Mozilla Firefox
  • Safari
  • Microsoft Edge
